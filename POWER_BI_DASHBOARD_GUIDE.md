### 2. Data Model & Relationships
1. **Fact Table**: `final_coldchain_analytics.csv`
   - Primary Key: `Shipment_ID`
   - Core Granularity: One row per reefer transit shipment
2. **Dimension Table 1**: `carrier_reliability_benchmarks.csv`
   - Key: `Carrier_Name` (1-to-Many relationship with Fact table)
3. **Drift Telemetry Table**: `sql_thermal_drift_window.csv`
   - Key: `Shipment_ID` (1-to-Many relationship with Fact table)

### 3. Core Power BI DAX Measures (Copy-Paste Ready)

#### Measure 1: On-Time In-Full (OTIF) Quality Compliance Rate (%)
```dax
OTIF Quality Compliance % = 
VAR TotalLoads = COUNTROWS('final_coldchain_analytics')
VAR SafeLoads = CALCULATE(COUNTROWS('final_coldchain_analytics'), 'final_coldchain_analytics'[Spoilage_Flag] = 0)
RETURN
DIVIDE(SafeLoads, TotalLoads, 0) * 100
```

#### Measure 2: Financial Cargo Value at Risk ($ USD)
```dax
Cargo Value at Risk USD = 
CALCULATE(
    SUM('final_coldchain_analytics'[Cargo_Value_USD]),
    'final_coldchain_analytics'[Spoilage_Flag] = 1
)
```

#### Measure 3: Critical Thermal Excursion Rate (%)
```dax
Critical Excursion Incident Rate % = 
DIVIDE(
    CALCULATE(COUNTROWS('final_coldchain_analytics'), 'final_coldchain_analytics'[Thermal_Excursion_Minutes] > 60),
    COUNTROWS('final_coldchain_analytics'),
    0
) * 100
```

#### Measure 4: Average Mean Kinetic Temperature (MKT)
```dax
Avg MKT Deg C = 
AVERAGE('final_coldchain_analytics'[Mean_Kinetic_Temp_C])
```

#### Measure 5: AB InBev Beer Quality Integrity Index (%)
```dax
AB InBev Beer Compliance % = 
VAR TotalBeer = CALCULATE(COUNTROWS('final_coldchain_analytics'), 'final_coldchain_analytics'[Cargo_Type] = "Pasteurized Keg Beer / Premium Lager")
VAR SafeBeer = CALCULATE(COUNTROWS('final_coldchain_analytics'), 'final_coldchain_analytics'[Cargo_Type] = "Pasteurized Keg Beer / Premium Lager", 'final_coldchain_analytics'[Spoilage_Flag] = 0)
RETURN
DIVIDE(SafeBeer, TotalBeer, 0) * 100
```

### 4. Executive Canvas Layout Blueprint (Page Layout)

#### Section A: Top KPI Banner (5 Cards)
- **Card 1**: Total Shipments Dispatched (`1,200`)
- **Card 2**: OTIF Quality Compliance (`81.8%` | Target: `85.0%`)
- **Card 3**: Critical Risk Alerts (`Predicted_Spoilage_Risk >= 70%`)
- **Card 4**: Total Inventory Loss at Risk (`$15.2M`)
- **Card 5**: Mean Excursion Duration (`64.8 Minutes`)

#### Section B: Core Visualizations (Middle Row)
- **Visual 1 (Scatter Plot - Thermal Excursion Zone)**:
  - **X-Axis**: `Ambient_Peak_Temp_C`
  - **Y-Axis**: `Reefer_Max_Internal_Temp_C`
  - **Legend**: `Cargo_Type`
  - **Reference Line**: Constant Y = 8.0°C (Dotted Red line representing safe beer/vaccine threshold).
- **Visual 2 (Clustered Bar Chart - Carrier Reliability Scorecard)**:
  - **Y-Axis**: `Carrier_Name`
  - **X-Axis**: `OTIF Quality Compliance %`
  - **Color**: Conditional Formatting (Green $\ge 82\%$, Red $< 80\%$).

#### Section C: Root Cause & Route Intelligence (Bottom Row)
- **Visual 3 (Bar Chart - Door Breach Impact)**:
  - **X-Axis**: `Door_Open_Events` binned (1-3, 4-6, 7-10, >10)
  - **Y-Axis**: `Spoilage Rate %`
  - **Insight**: Highlights how urban multi-drop routes with >8 door opens elevate thermal risk by 300%.
- **Visual 4 (Decomposition Tree / Route Corridor Matrix)**:
  - **Category**: `Origin_Facility` -> `Destination_Facility` -> `Cargo_Type`
  - **Measure**: `Cargo Value at Risk USD`
